# Bảng chọn LAYOUT × STYLE — cho người dùng (tiếng Việt)

Skill **lắp layout** từ các "núm" dưới (như app, click đổi kiểu). **Chữ = token `[title]`/`[content]`
cô ấy điền · Ảnh = token `[image_N]`.** Chọn bằng số / tên / tả loáng thoáng — agent tự map. Không
chọn → agent tự lấy cái hợp dịp + đổi khác lần trước.

## 🧩 LAYOUT (lắp tự do)
**Logo:** 1 trái · 2 giữa · 3 phải   |   **Banner:** có / không
**Khối ảnh:**
| # | Kiểu | Hình |
|---|---|---|
| A | Không ảnh thân | chỉ chữ |
| B | 1 ảnh | 1 ảnh to |
| C | 2 ảnh ngang | `[img][img]` |
| D | 2×2 (4 ảnh) | 2 trên 2 dưới |
| E | 2 ảnh dọc + chữ | cặp ảnh 1 bên, chữ bên kia (đổi trái/phải) |

**Footer:** social (text / icon) + `[contact]` + `[unsubscribe]` + xem-online — luôn có.

## 🎨 STYLE (trông thế nào)
| # | Tên | Cảm giác |
|---|---|---|
| 1 | Tối giản hiện đại | trắng nhiều, chữ lớn, sạch |
| 2 | Tối sang (dark) | nền đen, header gradient |
| 3 | Sang trọng (luxe) | đen + vàng gold, nhiều khoảng trắng |
| 4 | Rực rỡ (bright) | màu nóng — hợp sale |
| 5 | Tạp chí (editorial) | hero lớn, chữ to thanh mảnh |
| 6 | Hai tông (duotone) | 2 màu xuyên suốt |
| 7 | Bento | thẻ bo tròn, trẻ trung |
| 8 | Cổ điển (classic) | truyền thống, an toàn |

## Lưu ý
- LAYOUT = *lắp khối thế nào* (logo/banner/ảnh/footer); STYLE = *trông thế nào* (màu/typo). Kết hợp tự do.
- Vd: "logo giữa + banner + 4 ảnh grid, style Tối giản" · "logo trái + 2 ảnh ngang, style Dark".
- Tả mơ hồ → agent chọn gần nhất + nói rõ đã chọn gì (tiếng Việt).
